# Selenium Java TestNG Framework

Web test automation practice project built with Java, Selenium WebDriver and TestNG, using the Page Object Model.

## What is covered
- Page Object Model: page classes in `Pages` (login, checkbox, dropdown, secure page) and test classes in `Tests`
- Selenium basics in `googleWeather`: implicit, explicit and fluent waits, alerts, windows, radio buttons, checkboxes, dropdowns and CSS selectors
- TestNG tests for login, checkbox and dropdown flows
- Suite run through `testng.xml` and a `TestRunner` class

## Tech stack
Java, Selenium WebDriver, TestNG, Eclipse

## How to run
1. Clone the repo and import it into Eclipse (File > Import > Existing Projects into Workspace).
2. Add the Selenium and TestNG libraries to the build path.
3. Right-click `testng.xml` > Run As > TestNG Suite.
